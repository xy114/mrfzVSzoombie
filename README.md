# 战术指挥终端 — 植物大战僵尸 × 明日方舟

一款融合经典 PvZ 塔防玩法与《明日方舟》干员体系的策略游戏。采用羊皮纸战术室美学风格，支持植物升星、皮肤装备、异客援护、编队管理等深度系统。

---

## 游戏概述

### 核心玩法
在 5×9 草坪网格上部署植物阻挡僵尸入侵，管理阳光资源，合理搭配阵容。融合了 Arknights 的**技能技力条**、**异客援护**、**干员升星**、**皮肤系统**等机制。

### 当前内容
- **4 种植物**：向日葵、豌豆射手、坚果、樱桃炸弹
- **1 位异客**：武士零（Katana Zero，时空斩击型援护角色）
- **4 种敌人**：普通僵尸、路障僵尸、持盾僵尸、小鬼僵尸
- **多关卡**：序章至第一章，包含普通与困难模式
- **皮肤系统**：豌豆射手「维什戴尔」皮肤（9000 晶核解锁）

## 游戏系统

### 植物系统
| 植物 | 阳光 | 特点 |
|------|------|------|
| 向日葵 | 50 | 持续生产阳光 |
| 豌豆射手 | 100 | 发射豌豆，技能：火焰豌豆（AOE 法术伤害） |
| 坚果 | 50 | 高生命值肉盾，技能：临时提升防御 |
| 樱桃炸弹 | 150 | 一次性范围爆炸，技能：备战引爆（400% 伤害） |

- **升星系统**：消耗晶核提升星级（1-3★），增加生命值、攻击力、缩短冷却
- **皮肤系统**：装备皮肤改变外观并附加攻击加成

### 敌人系统
| 敌人 | 威胁 | 特点 |
|------|------|------|
| 普通僵尸 | 1★ | 基础单位 |
| 路障僵尸 | 1★ | 较高生命值 |
| 持盾僵尸 | 2★ | 精英单位，物理防御 |
| 小鬼僵尸 | 1★ | 高速低生命值 |

- **生成规则**：精英敌人不在第一波出现，Boss 敌人仅在最后一波出现
- **图鉴系统**：遭遇后解锁，查看详细属性与描述

### 异客系统
- **武士零（Katana Zero）**：时空中游走的刀锋，纯技能型援护角色
  - 主动技能「时停斩」：时停 0.5 秒，10 连斩，每刀 50 伤害
  - 被动技能「同行斩」：受击时停 0.3 秒，反击造成高额伤害
- 编队时可选择异客出战，战斗中显示独立血条与技力条
- 撤退返还 50% 部署消耗

### 资源系统
| 资源 | 获取方式 | 用途 |
|------|---------|------|
| 阳光 | 向日葵产出 / 自然掉落 | 种植植物 |
| 晶核 | 关卡击败敌人掉落 | 升星、解锁皮肤、解锁编队格子 |

### 编队系统
- 出战前选择植物编队（初始 6 格，可消耗晶核扩展至 12 格）
- 异客编队独立 3 格
- 编队自动保存

## 技术栈

- **运行时**：Electron（桌面端）
- **渲染**：HTML5 Canvas（游戏画面）+ DOM（UI 界面）
- **语言**：JavaScript ES Modules
- **构建**：electron-builder（Windows + macOS 双平台 CI/CD）
- **样式**：羊皮纸战术室暖色调 UI（CSS 变量体系）

### 项目结构
```
mrfzVSzoombie/
├── electron/              # Electron 主进程
│   ├── main.js
│   └── preload.js
├── game/
│   ├── js/                # 游戏逻辑 (ES Modules)
│   │   ├── main.js        # 入口 + 战斗事件绑定
│   │   ├── Game.js        # 战斗管理器 (BattleManager)
│   │   ├── Lawn.js        # 草坪网格系统
│   │   ├── UIManager.js   # UI 管理 (页面/弹窗/图鉴/编队)
│   │   ├── StorageManager.js  # localStorage 存档
│   │   ├── WaveManager.js # 波次管理 (敌人生成规则)
│   │   ├── Visitor.js     # 异客基类 + 武士零
│   │   ├── PlantConfig.js # 植物/星级/皮肤定义
│   │   ├── ZombieConfig.js# 敌人定义
│   │   ├── VisitorConfig.js# 异客定义
│   │   ├── LevelConfig.js # 关卡配置
│   │   ├── constants.js   # 游戏常量
│   │   └── *Renderer.js   # 植物/僵尸/异客渲染器
│   └── css/
│       └── ui.css         # 全局样式 (羊皮纸战术室主题)
├── assets/                # 游戏资源 (图片/GIF)
└── index.html             # 主页面
```

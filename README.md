# 🌻 植物大战僵尸 - 植物 vs 僵尸塔防游戏

一款基于经典游戏灵感开发的塔防游戏，融合策略、资源管理和即时战斗元素。

---

## 📋 游戏概述

### 游戏名称
**植物大战僵尸 (Plant vs Zombie)**

### 游戏类型
- 🎮 塔防策略游戏
- 🕹️ 即时战斗
- 🌱 资源管理

### 核心玩法
玩家通过种植各种植物来防御僵尸入侵。植物会自动攻击僵尸，玩家需要合理规划资源（阳光）来种植最优的防御阵容。

### 游戏目标
阻止僵尸入侵你的草坪，坚持尽可能长的时间，挑战更高的波次！

---

## ✨ 游戏特色与创新点

### 核心特色
- 🎯 **经典塔防玩法**：5行9列的草坪网格，策略性布局植物
- ☀️ **资源管理系统**：收集阳光种植植物，合理分配资源
- 🌊 **波次挑战模式**：随着时间推移，僵尸波次难度递增
- 🎨 **卡通Q版风格**：可爱的植物和僵尸形象

### 创新功能
- 🔥 **技能系统**：豌豆射手可释放火焰豌豆，造成范围AOE伤害
- ⚡ **形态转换**：释放技能时植物展示特效动画
- 🎮 **多种操作方式**：支持鼠标点击和键盘快捷键

## 📦 安装与配置

### 系统要求
- **操作系统**: Windows 10/11 (推荐)
- **Node.js**: v20+
- **内存**: 至少 2GB RAM

### 开发环境安装

```bash
# 克隆项目
git clone <repository-url>
cd mrfzVSzoombie

# 安装依赖
npm install

# 启动开发模式
npm start
```

### 打包构建

```bash
# 构建 Windows 便携版
npm run build

# 构建 Windows 安装程序
npm run build:installer
```

### 运行已构建的程序
1. 构建完成后，在 `dist` 目录找到生成的可执行文件
2. 双击 `植物大战僵尸.exe` 启动游戏

## 🎮 游戏操作说明

### 鼠标操作
| 操作 | 说明 |
|------|------|
| 点击植物卡片 | 选择要种植的植物 |
| 点击草坪格子 | 在选中位置种植植物 |
| 点击阳光 | 收集阳光（+25阳光） |
| 点击豌豆射手 | 释放技能（如果技能就绪） |

### 键盘操作
| 按键 | 功能 |
|------|------|
| **空格键** | 释放豌豆射手技能 |
| **ESC** | 暂停游戏 |

### 游戏界面
- **顶部状态栏**: 显示当前阳光数量和波次信息
- **底部植物栏**: 可选择的植物卡片
- **中间草坪**: 5x9 的战斗区域

## 🎲 游戏系统详解

### 植物系统

| 植物 | 阳光消耗 | 功能描述 |
|------|---------|---------|
| 🌻 **向日葵** | 50 | 每20秒生产25阳光 |
| 🫛 **豌豆射手** | 100 | 自动发射豌豆攻击僵尸 |

### 僵尸系统

| 僵尸 | 生命值 | 速度 | 特点 |
|------|-------|------|------|
| 🧟 **普通僵尸** | 100 | 正常 | 基础僵尸单位 |
| 🚧 **路障僵尸** | 200 | 正常 | 携带路障，生命值更高 |

### 技能系统

#### 豌豆射手 - 火焰豌豆
- **技能效果**: 发射一颗火焰豌豆，触碰到僵尸时爆炸
- **伤害范围**: 3x3 格子范围内的所有僵尸
- **伤害值**: 150点
- **冷却时间**: 15秒

### 战斗系统
- 植物自动攻击前方的僵尸
- 子弹与僵尸碰撞检测
- 僵尸到达草坪左侧则游戏失败

### 波次系统
- 每30秒生成一波僵尸
- 波次越高，僵尸数量和种类越多
- 支持普通僵尸和路障僵尸混合波次

# 植物大战僵尸风格塔防游戏 - 设计方案

## 1. 项目概述

| 属性 | 内容 |
|------|------|
| 项目名称 | 植物大战僵尸风格塔防游戏 |
| 项目类型 | Windows 桌面客户端游戏 |
| 技术栈 | HTML5 + JavaScript + Electron |
| 美术风格 | 卡通Q版，色彩鲜艳 |
| 项目阶段 | 核心体验版 (MVP) |

## 2. 平台与技术

### 2.1 目标平台
- **Windows 桌面客户端**
- 使用 Electron 框架打包为独立 .exe 文件

### 2.2 技术选型理由
- HTML5/JavaScript 技术栈，学习曲线平缓
- 大一学生已有 Web 基础，无需学习新语言
- Electron 可快速打包为桌面应用
- 调试方便，浏览器 F12 即可
- 教程资源丰富，社区活跃

## 3. 游戏内容范围

### 3.1 核心体验版 (MVP)
专注于验证核心玩法，快速出成果。

### 3.2 植物角色

| 植物 | 功能 | 技能 |
|------|------|------|
| 🌻 向日葵 | 生产阳光资源 | 无 |
| 🫛 豌豆射手 | 发射豌豆攻击僵尸 | 🔥 火焰豌豆 (3×3 AOE) |

### 3.3 僵尸角色

| 僵尸 | 特点 |
|------|------|
| 🧟 普通僵尸 | 基础款，稳步前进 |
| 🚧 路障僵尸 | 头顶路障，生命值更高 |

### 3.4 关卡模式
- 单关卡无限波次挑战
- 波次难度逐渐递增
- 可重复游玩

## 4. 核心玩法循环

1. **准备阶段**: 游戏开始前，玩家可在草坪上种植植物
2. **资源生产**: 向日葵定期生产阳光
3. **种植防御**: 消耗阳光种植豌豆射手
4. **僵尸入侵**: 僵尸从右侧持续入侵
5. **攻击应对**: 豌豆射手自动攻击前方僵尸
6. **技能释放**: 玩家可主动释放火焰豌豆技能（范围爆炸）
7. **波次挑战**: 坚持越久，波次越高，僵尸越多

## 5. 技能系统设计

### 5.1 豌豆射手技能 - 火焰豌豆

| 属性 | 内容 |
|------|------|
| 技能名称 | 火焰豌豆 |
| 触发方式 | 点击豌豆射手或快捷键释放 |
| 效果 | 发射一颗火焰豌豆，触碰敌人时爆炸 |
| 爆炸范围 | 3×3 格 |
| 伤害 | 范围伤害，可击杀多个僵尸 |
| 冷却时间 | 10 秒 |
| 视觉形态 | 豌豆射手变为火焰喷射形态，发射橙红色火焰豌豆 |

### 5.2 技能实现要点
- 火焰豌豆飞行速度较普通豌豆快
- 爆炸时播放粒子特效
- 爆炸范围内所有僵尸受到伤害
- 技能释放有明显的 UI 提示（冷却时间显示）

## 7. 核心类设计

### 7.1 游戏主循环 (Game)
- 管理游戏整体状态（开始、进行中、结束）
- 维护植物阵列、僵尸阵列、子弹阵列
- 定时器驱动游戏更新（60 FPS）
- 处理碰撞检测

### 7.2 植物系统
- Plant 基类：位置、生命周期、渲染
- Sunflower：定时生成 Sun 对象
- PeaShooter：定时生成 Bullet，响应技能释放

### 7.3 僵尸系统
- Zombie 基类：位置、移动、血量、动画
- NormalZombie：标准属性
- ConeZombie：更高血量

### 7.4 子弹系统
- Bullet：普通豌豆，单体伤害
- FireBullet：火焰豌豆，范围伤害 (3×3)，碰撞时爆炸

### 7.5 技能系统
- Skill：技能冷却、触发条件、形态切换
- FirePeaSkill：火焰豌豆技能实现

### 7.6 波次系统
- WaveManager：波次生成逻辑、难度递进
- 随波次增加，僵尸数量和生成频率提升

## 8. 视觉设计要点

### 8.1 UI 布局
- 顶部：阳光计数、波次显示
- 底部：植物卡片栏（可点击选择植物）
- 中央：5行 × 9列 草坪
- 右侧：僵尸入侵方向

### 8.2 美术风格
- 卡通Q版角色设计
- 圆润可爱造型
- 鲜艳明快的色彩
- 可使用 Emoji 或简单图形作为占位符

### 8.3 动画效果
- 植物攻击动画
- 僵尸行走动画
- 子弹飞行动画
- 火焰豌豆爆炸粒子效果
- 技能释放形态切换动画

## 9. 交互设计

### 9.1 鼠标操作
- 点击卡片选择植物
- 点击草坪格子种植
- 点击已种植的豌豆射手释放技能

### 9.2 键盘快捷键（可选）
- 空格键：释放豌豆射手技能
- ESC：暂停游戏

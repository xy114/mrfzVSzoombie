# 异客系统 & 武士零设计

## Context

在现有植物/敌人图鉴和战斗系统基础上，新增"异客"（Visitor）系统——来自世界之外的角色，拥有独立的时停机制和技能体系。首位异客：武士零（Katana Zero）。

## 一、关卡计时器 & 时间缩放

### 架构

`BattleManager.update(deltaTime)` 中引入全局 `timeScale`：

```
scaledDelta = deltaTime * this.timeScale
```

- 所有战斗内实体（植物、僵尸、子弹、阳光）统一使用 `scaledDelta`
- 武士零始终使用真实 `deltaTime`，不受 timeScale 影响
- 三档流速：正常 1.0 / 面板 0.25 / 时停 0.05
- 时停颜色切换：瞬间完成，Canvas 叠加 `rgba(160, 0, 200, 0.2)` + 色彩矩阵变换

### 影响范围

仅战斗场景，不包括 UI 动画和主菜单。

## 二、武士零（Katana Zero）

### 基础属性

| 属性 | 值 |
|------|-----|
| HP | 300 |
| 普攻 | 无（纯技能型） |
| 养成 | 不参与升星/皮肤系统 |

### 主动技能

1. 点击武士零 → 面板从左侧弹出 → 时间流速 0.25x
2. 点击技能按钮 → 面板关闭 → 瞬间进入时停 0.05x
3. 0.5s 内瞬间 10 刀命中所有敌人
4. 每刀伤害：50 + 10% 受击敌人最大 HP
5. 刀光采用轨迹方案（C）：敌人周围多道刀光（`resources/special/刀光.png`），0.1s 后消失
6. 退出时停，恢复 1x
7. 冷却：10s

### 被动技能

1. 武士零受击 → 进入时停 0.3s
2. 对面前同一行所有敌人释放斩击
3. 伤害：100 + 70% 受击敌人最大 HP
4. 刀光覆盖方案（A）：刀光图片叠加在敌人 sprite 上方，0.1s 消失
5. 敌人暂停行动，刀光消失后恢复
6. 退出时停
7. 内置冷却：3s
8. 面前一行无敌人时：照样时停 0.3s，无伤害

### 形态渲染

- 常态：Katana Zero.jpg
- 时停时：叠加 Katana Zero time.png

### 伤害数字

- 红色粗体带描边，冲击放大效果
- 10 刀结算为总伤害数字

## 三、战斗内面板

- **触发**：点击武士零
- **位置**：屏幕左侧弹出
- **流速**：打开时全场 0.25x
- **内容**：立绘（Katana Zero.jpg）、名称"？？？"、HP/ATK 数值、主动技能（图标+描述+冷却环）、被动技能（描述+冷却）
- **关闭**：点击面板外任意位置 → 恢复 1x
- **技能触发**：点击技能按钮 → 面板关闭 → 进入时停

## 四、拖拽放置

植物和异客统一改为拖拽放置：

- 卡面按下鼠标 → 拖动 → 草坪格子松开放置
- 拖拽中显示半透明幽灵，有效格子高亮
- 无效位置松开：幽灵消失、卡面恢复、格子短暂红色闪烁
- 异客放置后卡面变灰（不可再拖），每人限放一次

## 五、编队界面

- 植物编队网格下方新增异客行（最多 3 槽位）
- 标题"？？？"，副标题"你准备好放弃大脑了吗"
- 异客槽位点击 → 复用植物选择器，过滤异客类型
- 异客不耗阳光
- 空槽位在战斗中不显示卡面
